## Roadi facts supplied by user

Roadi is an Android vehicle-management app. It supports vehicle, fueling, maintenance, expense, statistics, reminder, local storage, export/import and notifications. It does not require an account, does not use ads, does not actively collect GPS, contacts, photos/video, microphone/audio, calls/SMS, health, credit card/payment, advertising ID, or login data according to the supplied privacy policy. Vehicle information is voluntarily entered and stored locally. Export/share can send data to third-party services selected by the user.

## Preliminary recommendations

- App type: App, not Game.
- Category: Auto & Vehicles is the closest category if available in the console; otherwise choose the closest vehicle/transportation category actually offered by the console.
- Tags: choose only tags clearly supported by the app; candidate tags include Vehicle management, Maintenance, Fuel tracking, Expense tracking, and Reminders, subject to the exact tags offered by Play Console. Google allows up to five tags.
- Ads: No, provided the released APK/AAB contains no ad SDK, banner, interstitial, native ad, or house-ad promotion that meets Google's ad definition.
- Target audience: not designed for children; select only adult/older age groups that accurately match the product strategy. Do not include child age groups unless the app is designed for them.
- Content rating: complete the IARC questionnaire accurately. Based on the supplied features, expect no mature/sexual/violent/gambling content, but the final rating is generated by the questionnaire and rating authorities.
- Data safety: still required even when no data is collected/shared. Must inspect the actual APK/AAB and every SDK before selecting No. Local-only user-entered vehicle data may still count depending on Google's definitions and whether it leaves the device; export/share through user-selected third parties must be evaluated carefully.
- Privacy policy URL: use the active GitHub Pages URL https://billysung.github.io/roadi-privacy-policy/ and keep the link accessible both in the store listing and in-app if sensitive permissions or child targeting apply.
- Sign-in details: no login instructions if the app truly has no account or restricted area.
- Sensitive permissions: declare only permissions present in the final manifest; notification permission may appear on newer Android versions but is not itself proof of personal-data collection.
- Advertising ID: choose No only after confirming the final manifest and SDK dependency tree do not include advertising/analytics use that requires it.

## Import file clarification

The user screenshot is the Play Console Store listing page in Traditional Chinese, showing the AI-assisted translation import option under common text assets. Official Google documentation confirms that store listing translations can be added manually or through Play Console translation services, and that structured files such as CSV or Google Sheets may be used. The exact current CSV schema was not exposed in the official public help page; therefore, do not invent a schema. Safest next step is to use Play Console's own Download template / Export function if shown, or ask the user to attach the template/exported CSV. Then populate the template with Roadi's exact zh-TW and English strings while preserving its headers and encoding.
